开始

选择聚类算法Choose an Algorithm

首页提供两种基于分布差异的聚类算法，均适用于「对象 + 重复观测记录」的数据结构，可从首页点击进入：

  • KSKC（Kolmogorov–Smirnov K-means 聚类）：用两样本 Kolmogorov–Smirnov 统计量度量分布差异，在 K-means 框架下迭代划分，对分布整体形态差异敏感；
  • WSC（Wasserstein 谱聚类）：用一维 Wasserstein 距离度量分布差异，构造相似度矩阵并稀疏化后以谱聚类划分，善于捕捉局部分布结构，计算更快。

两个应用的页面结构与操作流程一致，仅参数项不同。

准备

准备数据：CSV 格式要求Prepare Data: CSV Format

DiCA 适用于对象具有多条重复观测记录的场景（如商户的多笔交易、用户的多次消费）。输入为标准 CSV 文件，至少包含两列：

  • 对象标识列：区分不同对象的 ID，如商户 ID、用户 ID、门店编号等；
  • 观测值列：对每个对象的重复观测数值，如交易金额、消费笔数、客单价等。

每行为一条观测记录。以交易数据为例，文件内容形如：

Merchant_id（对象标识）Transaction（观测值）
mer001100.00
mer001105.50
mer00250.20
mer00245.80

平台会为每个对象构建其观测值的经验分布，再按分布之间的差异对对象聚类——分布形态相似的对象会被分到同一簇。

每个应用的上传区都提供「下载测试数据」链接，可直接下载 test_data.csv（600 个商户、约 7.8 万条交易记录）快速体验。

第二步：设置聚类参数并运行Step 2: Set Parameters & Run

上传完成后，「聚类参数」卡片中的对象列与观测值列会被自动识别（也可手动更换）。两个算法共有的核心参数：

  • 对象标识列 / 观测值列：指定哪一列是对象 ID、哪一列是观测数值；
  • 簇数 K：希望聚成几类（默认 3）。

算法特有的超参数：

  • KSKC：并行线程数（默认 4）、度数校正（默认否）等；
  • WSC：高斯核带宽 σ（默认取距离中位数）、稀疏化方式（K 近邻 / LOF 离群剪枝 / 不稀疏化）、近邻数 k0（默认 10）等。

参数设置：确认列与簇数，点击「运行聚类」

点击「运行聚类」后，下方会实时显示算法日志（对象数量、迭代进度等）：

03

第三步：查看聚类结果Step 3: Explore Results

聚类完成后，页面展示三部分结果：

  • 统计卡片：每个簇的对象数、记录数与均值，快速把握各簇规模；
  • 分布对比图：所有簇的分布画在同一张图中，带图例、可悬停查看数值；
  • 分配明细：每个对象归属的簇标签表格。

分布对比图支持三种视角切换（默认展示密度分布）：

  • 密度分布：核密度估计曲线，能最直观地看出各簇观测值的"峰"在哪里、形态有何不同；
  • 经验累积分布 (ECDF)：每个簇把簇内所有对象的观测值汇总后画出的经验累积分布函数，纵轴 F(x) 表示取值不超过 x 的比例；
  • 直方图：统一分箱的频率密度直方图，与密度曲线相互印证。

FAQ

常见问题FAQ

Q：KSKC 和 WSC 该怎么选？
A：两者都是基于分布差异的聚类。KSKC 是迭代式方法，对分布整体形态敏感；WSC 把聚类转化为图割问题，计算更快（数百个对象通常几秒完成）。建议都跑一遍对比结果。

Q：聚类需要多长时间？
A：取决于对象数与记录数。WSC 通常数秒完成；KSKC 数据量大时可能需数分钟，运行期间可看实时日志。

Q：簇数 K 应该设多少？
A：没有唯一答案。建议结合业务含义尝试多个 K（如 3、4、5），观察分布对比图中各簇形态差异是否明显、各簇规模是否合理。

Q：WSC 的 σ（带宽）和稀疏化方式怎么设置？
A：σ 留空即自动取距离中位数；稀疏化推荐「K 近邻」（近邻数 k0 默认 10）。LOF 离群剪枝是另一种稀疏化选择，可对比效果。
